## 一、概述

### 1.1 范围与编号

- **P2-01 ~ P2-28**：本次 28 个工作项，来源三处（§五 P2 项、§八第三批未被 P1 清偿的余量、§十三登记项）。P3 杂项（仪表盘下钻、团队生产力矛盾、AVATAR 协议头、DOM 嵌套警告）**不在本计划**。
- P1 批已提前清偿 §八第三批部分项（键盘流/依赖 UI/迭代/批量/面板搜索/表格 chips），不重复立项；其尾巴 DataTable 平移单列为 P2-06。

### 1.2 执行原则（与 P1 批一致）

1. 按文件域分组、组间互不重叠，组内子代理并行（**同时最多 3 个**）。
2. **i18n 键今晚下放子代理**：各子代理只准添加自己模块前缀的键到 `zh/en` 两份 locale（用 Edit 工具、禁止重排/格式化 locale 文件、禁止动他人前缀）；主线程收口跑 `check-i18n-sync`。
3. **openapi 契约变更**：子代理改 DTO/controller 与契约描述，`contract:export` 再生成双份 `api-types.gen.ts` 由主线程统一收口。
4. 涉及产品口径与生产数据的不替用户决定（§三裁决项），裁决未到只做无争议部分。
5. 每批收口跑该批验证关口，全绿才进下一批。
6. **主工作树有并行会话的 auth 在途改动（login-page/register-page/api-client/auth-components），全程禁碰**；提交一律精确 `git add <paths>`。
