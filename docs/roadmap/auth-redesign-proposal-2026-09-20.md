# 登录/注册/欢迎页改版设计方案（参考 Qoder 风格）

- 日期：2026-09-20
- 状态：**待裁决**（裁决点 D1~D6，见 §九）
- 范围：`modules/auth` 三页视觉改版 + 新增 `/welcome` 欢迎页（身份卡）；**零后端改动**
- 前置：拍板后走 `requirement-intake` 五步登记，实现阶段按 `frontend-page` skill 流程执行
- 参考：Qoder 登录页 + 注册欢迎身份卡截图（2026-09-20 用户提供）

---

## 一、参考拆解：Qoder 这套设计好在哪

1. **左文右图的分栏语法**：左侧大量留白 + 拟人化标题（「欢迎你，我的朋友 👋」）+ 操作区贴底一行排开；右侧满高圆角插画。把「登录」从表单事件变成「见面」事件。
2. **两段式旅程**：登录页（品牌问候）→ 注册成功页（身份卡仪式感）。注册的终点不是「表单提交成功」，而是「入职」。
3. **身份卡**：成员编号 + 入职日期 + 环形口号 + 签名，把冷冰冰的「账号」翻译成「身份与归属」。
4. **克制的色彩**：全局只有深绿一个强调色，其余全靠黑白灰层次。

## 二、APM 语境转译

| Qoder | APM 对应 | 转译说明 |
|---|---|---|
| Agent Coding 平台 | AI 驱动的项目管理平台 | 副文案讲「AI 同事是手段，工程治理是目的」 |
| 「我的朋友」 | 「同事」 | APM 的隐喻是**入职一个有 AI 同事的团队**，不是交个朋友 |
| 身份卡（JOINED QODER） | **工牌**（Member 体系天然支持） | displayName + 成员编号 + 入职日期 + 签名 |
| SSO 按钮先行（页上无表单） | 账密表单直接进左栏 | APM 是账密登录，「按钮先展开表单」纯增步骤，不做 |
| 深绿主按钮 | `--accent-green`（156 38% 40%） | **与现主题 token 几乎同色，零新增色板** |

## 三、页面清单与流程

```
/login      登录（改版）
/register   注册（改版，含邀请预览 banner）
/welcome    【新增】注册成功欢迎页 = 左侧祝贺文案 + 右侧身份工牌
```

流程变化：`/register` 成功后由「直接跳 /app/projects」改为「进 /welcome → 开始使用 → /app/projects」。桌面端 OnboardingGate 初始化向导**不动**（D3）。

## 四、布局规格（auth-shell，三页共用）

- **桌面 ≥1024px**：左右分栏。左栏内容宽 `max-w-[26rem]`、纵向三段 `justify-between`：上 logo → 中（标题/表单）→ 下（操作区 + 页脚链接）；右栏 `flex-1`，内边距 16px，圆角 `rounded-3xl` 满高视觉面板。
- **<1024px**：右栏隐藏，表单居中全宽，仅保留顶部 logo（参考图为桌面产品图，APM web 必须可响应）。
- **暗色模式**：全部走既有 token；右栏渐变换暗色变体。
- **作用域**：新建 `auth-shell.tsx`，仅 auth 路由作用域内可覆写品牌变量（见 D4）。

## 六、右侧视觉面板（裁决点 D1）

- **A（推荐）产品拼贴**：`accent-green → accent-blue` 低饱和渐变底 + 细网格/噪点纹理；浮 3 张迷你卡——工单卡、决策卡、AI 同事头像卡，全部按既有组件形态微缩重绘（纯 div/SVG，复用 design token）。零资产依赖、暗色好适配、讲产品故事。
- **B 插画**：情绪最贴参考图，但需资产。v1 用 A 占位，后续 AI 生成插画入库 `public/` 热替换（auth-visual 做成可切换槽位）。
- **C 纯抽象渐变**：最稳，无记忆点，不推荐单独用。

## 七、颜色与主色（裁决点 D4）

- 全局 `--primary` 保持中性近黑不动（Linear 基因，全仓按钮一致性）。
- 方案：仅 `auth-shell` 作用域内覆写 `--primary: var(--accent-green)`——登录/注册/欢迎三页主按钮呈参考图深绿，进门有品牌仪式感，产品内不受扰。
- 备选：不覆写，主按钮维持黑色，绿色只出现在右栏视觉面板（更保守，一致性更强）。

## 八、实现清单（拍板后）

- 新增：`modules/auth/components/{auth-shell,member-card,auth-visual}.tsx`、`pages/welcome-page.tsx` + 路由 `/welcome`
- 改动：`login-page.tsx` / `register-page.tsx`（逻辑与错误处理不动，只换壳）、`locales/{zh,en}/*.json`（auth.* 键补全）
- 测试：`login-page.test` / `register-page.test` 适配壳结构 + 新增 `welcome-page.test`
- 零后端改动、零 schema 改动、零 openapi 变更
- 邀请落地页 `invite-page.tsx` 可复用同壳（P2 顺手项）
