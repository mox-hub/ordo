## A. 发布链人工环节（最高优先级，全部要你动手）

### A1. Publish v0.7.14 Draft（5 分钟）
1. 打开 GitHub 仓库 → Releases → 看到 `v0.7.14` 草稿（Draft）。
2. 核对三资产齐全：`.exe` 安装包 / `.blockmap` / `latest.yml`。
3. 点 Publish（发布后 electron-updater 的 feed 才会指向它；当前 Latest=0.7.13）。

### A2. 真干净机安装冒烟（GAP-T-19，文档体系唯一明示的发版前硬门槛）
1. 用一台从未装过 APM 的机器（或新建 Windows 本地用户 + 清 `%LOCALDEV%` 相关目录）。
2. 安装 0.7.13（或任一已发布版）→ 首启：注册首个用户 → 应自动成为 admin。
3. 建项目 → 建工单 → 改状态 → 退出重开：登录态与数据都在。

### A3. 自动更新整链首考（ADR-015，**出口条件①+②关键项，优先级最高**）
1. 干净机装 **0.7.6**（老版本基线）→ 首启完成注册。
2. 建少量真实数据（项目/工单/文档）。
3. 设置 → 关于 → 检查更新 → 应发现新版本并静默下载 → 按提示重启。
4. **验收点**：版本号=最新；**升级前自动备份已生成**（`.apm-backups` 有新目录）；重启后旧数据完整可读（跨 0.7.7→最新全部迁移链首考）。
5. 反向再看一遍更新提示 UI：releaseNotes 三形态展示、更新中状态、失败重试不卡死。

## B. v0.8.0 出口条件「三件套真机验收」（上线计划①）

### B1. 备份恢复实测（G7-a）
1. 预置数据：建项目 + 2 张工单。
2. 设置 → 工作区备份：先「全库备份」再「单区备份」各一份 → 列表出现两条、含文件大小。
3. 改库：删除其中 1 张工单（制造漂移）。
4. 恢复单区：选单区备份 → 强确认框**精确输入工作区名称** → 确认。
5. **验收点**：被删工单回来了；列表顶部多一条 `pre-restore` 自动备份（这是回滚保险）；错误 confirm（随便输）→ 400 拒绝且无任何副作用。
6. 进阶（可选）：全库 RESTORE ALL 需输入 `RESTORE ALL`；恢复后旧工作区注册表点时还原。

### B2. 旧版升级数据不丢（G7-b）——即 A3，若 A3 已过此项自动通过。

### B3. 隔离执行 + 成果合入（G5）
1. 选一个已绑仓库（本地路径）的工作区 → 派发一个会产生文件改动的真实任务给 AI 执行。
2. **验收点**：执行发生在隔离 cwd（执行详情可见工作目录）；执行完成后成果合入回主工作区（`git status` 可见产物/改动）；失败路径有结构化报错不静默。

### B4. 成本归因数字可对（G8）
1. 跑一次真实 AI 执行（产生 token 消耗）。
2. 三处对数：执行记录详情的成本 ↔ 办公室该成员「本周成本」↔ 统计/仪表盘成本卡。
3. **验收点**：三处同一口径能对上（真相源=AIUsageLog，按执行主体归因）；无用量处显示 0/占位而非编造数字。

## C+. v0.7.15 / 0.8.0 前批验收（2026-10-11 追加，随归版提交）

### C7. AI 员工引导闭环（GAP-T-68，5a3fcdb4）——首装硬阻断清偿，**最高优先**
1. 在 A2 的干净机上走完全程：注册 → 引导七步 → 「配置 AI」步填真实 Key 测试通过。
2. **验收点**：配置成功后到项目里建工单点「指派 AI」——下拉应出现「AI 助手」（自动创建的默认 AI 员工），**不再是空态**；引导完成步**不出现**「创建 AI 员工」行动卡（已自动建过）。
3. 跳过路径：另起引导 → 「配置 AI」步跳过 → 完成步应出现「创建你的第一个 AI 员工」行动卡 → 点击应落到成员页且**自动弹出** AI 页签的新建对话框。
4. 重复配置 AI（同库再走一遍配置步）→ 不重复建员工（handle 幂等，无报错）。

### C8. 清单页表格视图（CAP-A-29）+ 语义图表三件
1. 项目/工单/文档/执行记录/验收/发版/成员/团队/工作流九页：工具栏切「表格」档 → 列化渲染、行点击进详情、右键菜单与列表视图同源；切回 grid/list 无回归。
2. 全局仪表盘：成本环形占比（中心合计）、优先级构成条（斜纹余量）、图例网格 hover 正常。

### C9. AI 表面 DEV-only 化（ADR-019，1fcfe9a6）
1. **生产构建**（桌面壳加载 dist）：侧栏「协同与底座」组**无**「AI 表面」入口；命令面板搜「表面/AI 表面」无结果；直访 `/app/ai-surface` 走错误页兜底不白屏。
2. 引导完成步：主 CTA 是「直接进入 APM」，**无**回放按钮（生产态）。
3. DEV 态（pnpm dev）：侧栏系统组 DEV 徽标下「AI 表面」可达，回放正常播放。

### C10. 交付出口三件（9a052deb）
1. 文档详情页「更多」菜单：复制链接（toast 确认）→ 剪贴板即详情页 URL；导出 Markdown → 下载 `<标题>.md` 内容与正文一致；**菜单里不再有「分享/添加书签」**。
2. 验收详情页跑一次审计 → 报告面板右上「导出报告」→ 下载 Markdown：头部时间/风险/摘要 + 阻塞/建议/通过三组与页面一致。
3. 发版详情：把一张发版推到 released（或取既有 released 发版）→ 出现「标记已部署」按钮 → 点击填备注确认 → MetaBar 出现绿色「已部署」胶囊（时间+备注）；非 released 发版**不出现**该按钮。

### C11. CLI provider argv 预检（495abf8d）
1. 给 AI 成员配 gemini-cli/qwen 等 argv 家 provider → 构造一个超长任务描述（>8000 字符，如粘贴长文档）派发 → **派发即被拒**，报错含长度数字与「切换 claude-code」指引（不是烧完执行才截断失败）。
2. claude-code/zcode 成员派同样长任务 → 正常派发（免疫）。

### C12. 引导七步统一（a064e451）+ 文档三件（286b4250）
1. Web（浏览器 5173）走引导：恒 7 步（与桌面同序），工作目录步显只读三态（无运行时=空态指引）；底栏收栏不随内容滚动。
2. 仓库根 README 快速上手章节与实际流程一致；GitHub 仓库 Issues 页出现「Bug 报告/功能建议」模板选择器；帮助页尾部有反馈卡、点击直达 issue 选择器。

## C. 本批新功能验收（2026-10-03～10-10 六个提交批次）

### C1. 引导窗口改版（CAP-A-18 切片，f4eafd8a）
1. 制造首启态：新装机（A2 的机器天然满足）或开发者控制台清 `app-storage`。
2. 打开桌面壳 → 向导**自动弹出**，双栏 896px、左竖步骤轨共 7 步。
3. 第 3 步「环境检查」（桌面模式才有）：未装 node/git/CLI 的卡显示平台安装命令 + 官方下载链接 + 复检；装了的显版本。**不强制设卡**，可跳过。
4. 「连接仓库」步：已有项目时出现真实绑定入口（BindRepositoryDialog）；无项目回落静态指引。
5. 「配置 AI」步：选厂家 → 填 API Key/Base URL → 测试连接 → **通过才允许落库并设默认模型**（故意填错 key 应被拦下、不假成功）。
6. 触发一次性：向导里 ESC/遮罩/关闭钮关掉 → 落完成标记；重启壳**不再自动弹**；侧边栏系统组「引导」入口可手动重开；从侧边栏进入的向导点「进入 APM」能正常关闭。

### C2. path-input 路径选择组件（CAP-A-28，2378e319）——六处消费点各过一遍
项目工作区绑定面板 / 接入向导 / 绑定仓库对话框 / 仓库列表新建表单 / 新建工作区页 / 设置 Git 可执行路径：
- 手输路径 → 失焦触发后端实测 → 徽标 valid/invalid；目录不存在 → 出「创建目录」动作 → 点击创建后转 valid。
- 桌面壳内出现系统选择器按钮（纯 Web 下隐藏，手输兜底）。
- 修改已填值后旧验证结论立即作废（不显示陈旧 ✓）。

### C3. AI 双修 + 保存实测闸门（da39ed71）
1. Grill 拷问：连续作答 ≥2 轮 → 转录区**每轮只有一问一答**，无成对重复。
2. 助理面板：生成出站草稿后切换会话再切回 → 草稿**不重复发送**。
3. 设置 → AI 管理 → 默认模型：填一个**错误的 key** 保存 → 被拦（报后端结构化错误）；换正确 key → 「实测走通中…」→ 通过才落库。

### C4. 发版门禁 AI 就绪度（575b4de8）
1. 项目内建发版草案 → 完善说明 → 提交门禁。
2. **验收点**：门禁卡「上次检查」旁出现「AI 就绪度」概率条（<70% 转黄）；未配置 AI/判定失败时**整块安静隐藏**、门禁本身照常工作（advisory 不改判定）。

### C5. 首装空库补种（d26de2d1）——与 A2 合并验收
首个注册用户=admin；工单/项目的状态下拉出现内置七态/五态；AI 连接槽位预置。

### C6. 认证窗与杂项（974b9688 / 1de95e34）
登录/注册失败提示为右上 toast；认证窗铺满窗口。Dock 发送消息后输入栏保持展开；若干列表空态出现「新建」动作按钮。
